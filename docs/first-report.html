BRIEFLOOP / 使用指南

首次使用

先用一份材料完成自己的第一稿。

当前安装包：Mac 0.25.0、Windows 0.23.1。按钮与能力因渠道不同，以所装版本为准；不代表开发中功能已经随安装包发布。

前置条件

准备可备份的工作区；需要模型的操作须先完成宿主认证，并确认材料允许交给所选服务处理。

操作步骤

  1. 安装桌面版并打开一个独立工作区。工作区保存材料、稿件、对话和运行记录。
  2. 在设置中选择已安装并完成认证的宿主与模型。先确认材料允许发送给该服务。
  3. 新建报告，写清读者、日期范围、需要回答的问题及目标篇幅；加入一份公开材料。
  4. 启动生成后进入等待页，查看实际进度；可切换已保存稿件。在“我的报告”继续查看阶段、等待与运行时间，再打开正文检查引用并编辑。
  5. 从导出菜单生成 Word；完成后下载并用 Word 或 WPS 打开。

成功后应该看到什么

成功时能看到已保存的稿件版本和可打开的 Word 文件。排队、开始生成或出现下载按钮本身都不代表文件已完成。

失败与边界

没有模型账号时先阅读网站的使用说明；若所装版本提供“先看合成示例”，可离线体验编辑和导出，但它不是实际模型生成或独立审阅的报告。
