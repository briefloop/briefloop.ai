Sources and review

Distinguish saved, linked, scored and reviewed content.

Current installers: Mac 0.22.2, Windows 0.22.2. Labels and capabilities vary by channel; the installer version is authoritative. Development features are not implied.

Before you start

Use a workspace you can back up. Model tasks require an authenticated runtime and permission to process the chosen materials.

Steps

  1. Open citations to inspect the source title, date and excerpt, and consult originals where needed.
  2. For important figures, check entity, period, units, denominators and calculations. Preserve source conflicts rather than resolving them with a secondary summary.
  3. Read scores and specific findings for the current version; an old score does not automatically apply to a rewritten draft.
  4. If your version supports independent review, inspect its actual scope and unchecked items. A prompt alone cannot provide read-only isolation when the runtime lacks it.
  5. Ask BriefLoop to revise findings, or edit and save yourself, then check the new version. Downloading a working draft is separate from eligibility for formal delivery.

What success looks like

Each resolved issue should correspond to a change in the new version, with review scope and unresolved issues visible. A source link or binding alone is not factual proof.

If something goes wrong

Scanned PDFs, images and Excel formulas without cached values may need additional checks. Do not call a draft formally deliverable while it contains material errors, core evidence gaps or unresolved material conflicts.
