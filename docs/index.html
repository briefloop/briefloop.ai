使用文档

安装、成稿、看依据、导出。按你现在要完成的事情查找步骤。

搜索在浏览器本地进行，不向服务发送关键词。

    • 首次使用

      先用一份材料完成自己的第一稿。

    • 安装与更新

      选对安装包，保留工作区后更新。

    • 接入模型与费用

      知道谁执行任务、谁接收内容、谁计费。

    • 搜索与任务进度

      选择搜索渠道，明确报告期间，跟踪实际进展。

    • 制作和修改报告

      从材料、要求到可持续修改的正文。

    • 看依据与处理问题

      区分已保存、已关联、已评分与已核查。

    • 模板与图表

      分别管理内容方法、版式和图表数据。

    • 反馈与下一次报告

      让具体修订成为可检查、可回退的经验。

    • 常见问题与数据说明

      知道如何保稿、停止任务及管理材料外发。

    • 外部 Agent 与 CLI

      让已有 Agent 调用 BriefLoop，提交报告、保存修订并下载指定版本的 Word。
