BRIEFLOOP / 使用指南

制作和修改报告

从材料、要求到可持续修改的正文。

适用于桌面 0.20.3 与 0.20.x 服务的基本流程。按钮与能力因渠道不同，以所装版本为准；不代表开发中功能已经随安装包发布。

前置条件

准备可备份的工作区；需要模型的操作须先完成宿主认证，并确认材料允许交给所选服务处理。

操作步骤

  1. 新建报告，明确读者、用途、期间与必须回答的问题。历史财报与当月动态应分别标注期间。
  2. 加入原始材料；搜索摘要仅作为发现线索。核对来源的日期、主体和口径。
  3. 生成后先阅读结论与表格，再检查关键引用。低分或审阅未通过的工作稿仍可查看和下载。
  4. 在正文编辑后保存，或把具体修改要求发给 BriefLoop。保留原稿，确认修改形成新版本。
  5. 保存后生成 Word。导出固定点击时的已保存版本，之后的修改需要再次导出。

成功后应该看到什么

正文、版本记录与导出的内容应对应。网页用于编辑，最终分页在 Word/WPS 中核对。

失败与边界

如果生成失败，先检查任务日志和已保存产物，再按实际错误恢复。不要重复提交同一报告来代替恢复；未保存的编辑也不会自动进入旧导出。
