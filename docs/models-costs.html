BRIEFLOOP / 使用指南

接入模型与费用

知道谁执行任务、谁接收内容、谁计费。

当前安装包：Mac 0.25.0、Windows 0.23.1。按钮与能力因渠道不同，以所装版本为准；不代表开发中功能已经随安装包发布。

前置条件

准备可备份的工作区；需要模型的操作须先完成宿主认证，并确认材料允许交给所选服务处理。

操作步骤

  1. 在设置中选择 BriefLoop Agent 或 Agent CLI。内置 Agent 直接配置模型服务；使用 CLI 时，先在对应工具中完成登录或 API 配置。模型用量由所选服务账户承担。
  2. 使用当前执行工具实际支持的模型和推理档位。0.25.0 支持 OpenCode 1.x 与 2.x；v2 的 Provider 配置在 OpenCode 中完成。保存配置不等于连接成功，用一小段公开文字验证。
  3. 主链、Evaluator、Wiki Maintainer 与 Skill Proposer 可分别指定模型。留空继承主链时，学习和评价同样可能调用模型。
  4. 为报告设置检索量、篇幅和执行时限。这些控制不等同于完整费用上限，宿主自带搜索的计量能力也不同。
  5. 在模型与搜索提供方后台核对实际额度及账单。BriefLoop 不提供这些服务的订阅或模型额度。

成功后应该看到什么

首次对话应有实际回复。后续新任务使用保存的配置，正在运行或已排队的任务保留原配置。

失败与边界

额度不足、429、503 或模型不存在时，先查看任务错误及宿主登录状态。不要只因为模型名字相同就假设订阅互通。只读权限和联网控制依宿主能力而异。
