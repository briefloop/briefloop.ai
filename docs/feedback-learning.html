BRIEFLOOP / 使用指南

反馈与下一次报告

让具体修订成为可检查、可回退的经验。

当前安装包：Mac 0.24.0、Windows 0.23.1。按钮与能力因渠道不同，以所装版本为准；不代表开发中功能已经随安装包发布。

前置条件

准备可备份的工作区；需要模型的操作须先完成宿主认证，并确认材料允许交给所选服务处理。

操作步骤

  1. 指出需要保留的写法或修改原因，尽量明确适用条件，而不只留下一个分数。
  2. 在设置的反馈与学习中决定是否开启自动学习，并设置最多尝试轮数 K；每轮可能增加模型耗时和用量。
  3. 查看 Wiki 中整理的经验与候选技能。Wiki 是方法经验，不是当期事实来源。
  4. 查看验证结果和采用状态；有候选文件不等于已经启用，任务运行也不等于产生收益。
  5. 若采用结果不合适，使用当前版本提供的回退入口并确认有效技能状态；保留原始反馈与比较记录。

成功后应该看到什么

应能分清原始反馈、候选、验证结果和当前采用内容。反馈可整理成经验，比较后再决定是否采用；不保证每轮分数提高。

失败与边界

暂停或额度不足时保留记录，按页面提示恢复。明确的人类要求与评分器自动建议的优先级策略有版本差异；不要把开发中策略当作旧安装包已经支持。
