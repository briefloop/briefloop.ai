常见问题与数据说明

知道如何保稿、停止任务及管理材料外发。

适用于桌面 0.21.0 与 0.20.x 服务的基本流程。按钮与能力因渠道不同，以所装版本为准；不代表开发中功能已经随安装包发布。

前置条件

准备可备份的工作区；需要模型的操作须先完成宿主认证，并确认材料允许交给所选服务处理。

操作步骤

  1. 工作区与记录保存在本地。使用云端模型时，任务、材料、稿件或反馈中的相关内容会发送给所选服务。
  2. 搜索词发送给搜索服务，网页请求到达目标网站；MCP 参数与必要认证发送给所配置的连接器。本地 stdio 程序也可能联网。
  3. 关闭公开检索不等于停止向模型发送内容，也不等于每个宿主的网络隔离。自定义网关或代理同样可能接收请求。
  4. 任务需停止时使用应用提供的停止入口，等待状态结束。关闭浏览器不停止独立后台服务；桌面退出按保存和任务处理提示操作。
  5. 备份时在任务空闲后复制整个工作区。分享日志、审计包或目录前检查材料与个人信息，不要包含凭据。

成功后应该看到什么

失败后已保存的稿件与材料应仍可查看。删除本地副本不会删除第三方已收到的内容，第三方留存规则由服务与账户配置决定。

失败与边界

HTTP 403、下载失败或依赖失败应按具体阶段排查，不要反复卸载并删除工作区。优先记录版本和错误，使用官方发行页及宿主诊断；公开求助前删去凭据和敏感材料。
