Write and edit reports

Move from sources and requirements to an editable draft.

Applies to desktop 0.20.3 and the 0.20.x service. Labels and capabilities vary by channel; the installer version is authoritative. Development features are not implied.

Before you start

Use a workspace you can back up. Model tasks require an authenticated runtime and permission to process the chosen materials.

Steps

  1. Create a report with its audience, purpose, period and required questions. Distinguish historical financial periods from current-month events.
  2. Add original sources; use search snippets only as discovery leads. Check dates, entities and definitions.
  3. Read conclusions and tables, then inspect key citations. Working drafts remain visible and downloadable even with low scores or unresolved review issues.
  4. Edit and save the body, or give BriefLoop specific revision instructions. Preserve the original and confirm that changes create a new version.
  5. Generate Word after saving. Export uses the saved version fixed when requested; later edits require another export.

What success looks like

The body, version history and exported content should correspond. Edit in the browser and check final pagination in Word or WPS.

If something goes wrong

If generation fails, inspect task logs and saved artifacts before recovering. Do not submit duplicate reports as a substitute for recovery. Unsaved edits do not appear in an earlier export.
