Your first report

Create a first draft from one source.

Current installers: Mac 0.24.0, Windows 0.23.1. Labels and capabilities vary by channel; the installer version is authoritative. Development features are not implied.

Before you start

Use a workspace you can back up. Model tasks require an authenticated runtime and permission to process the chosen materials.

Steps

  1. Install the desktop app and open a separate workspace for sources, drafts, conversations and task records.
  2. In settings, select an installed, authenticated runtime and model. Confirm that your source may be sent to that service.
  3. Create a report. Specify the audience, date range, questions and target length, then add one public source.
  4. After starting, follow progress on the waiting page or switch to a saved draft. My reports shows stages, queue time and execution time; open the body to check citations and edit.
  5. Generate Word from the export menu. Download the completed file and open it in Word or WPS.

What success looks like

Success means a saved draft version and a Word file you can open. A queued task or download button alone is not proof of completion.

If something goes wrong

Without a model account, read these guides first. If your installed version offers a synthetic sample, it can demonstrate editing and export without a model; it is not an independently reviewed, model-generated report.
