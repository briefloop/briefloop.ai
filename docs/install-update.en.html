Install and update

Choose the right installer and preserve your workspace.

Current installers: Mac 0.24.0, Windows 0.23.1. Labels and capabilities vary by channel; the installer version is authoritative. Development features are not implied.

Before you start

Use a workspace you can back up. Model tasks require an authenticated runtime and permission to process the chosen materials.

Steps

  1. Choose the Apple silicon DMG or Windows x64 EXE on the download page. Check About This Mac for the chip; browser Intel labels are unreliable.
  2. Prepare Python 3.11 or later. A compatible existing 3.12 installation is supported; the app neither requires a new 3.11 download nor installs system Python automatically.
  3. On Mac, copy the app to Applications. On Windows, run the installer. Follow the first-launch steps to prepare app-specific dependencies.
  4. Install and authenticate a model CLI separately. Desktop bridges use Electron’s built-in Node; WebUI bridge runtimes need Node.js 20+.
  5. Save drafts and back up the entire workspace while tasks are idle. Check updates in settings. On Mac, replace the app in Finder; Windows uses its installer.
  6. Version 0.22.1 fixes an OpenCode service startup timeout encountered in the Windows desktop app. Update the desktop app before retrying if you encounter this issue.

What success looks like

After restarting, check the app version and open the original workspace to confirm drafts and sources. The PyPI package provides the service and WebUI, not the desktop app.

If something goes wrong

Initial Mac and Windows packages are unsigned; Mac packages are also not notarized. Verify the official source and SHA256, then use the OS permission for that app rather than disabling system protection. If updates fail, use official Releases; do not delete the workspace to fix a download.
