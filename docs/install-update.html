BRIEFLOOP / 使用指南

安装与更新

选对安装包，保留工作区后更新。

当前安装包：Mac 0.21.1、Windows 0.21.1。按钮与能力因渠道不同，以所装版本为准；不代表开发中功能已经随安装包发布。

前置条件

准备可备份的工作区；需要模型的操作须先完成宿主认证，并确认材料允许交给所选服务处理。

操作步骤

  1. 从下载页选择 Apple 芯片 Mac 的 DMG 或 Windows x64 的 EXE。Mac 芯片在“关于本机”查看；不要依据浏览器中的 Intel 字样判断。
  2. 准备 Python 3.11 或更高版本。已有兼容的 3.12 可以使用，App 不强制下载 3.11，也不自动安装系统 Python。
  3. Mac 将 App 拷入 Applications；Windows 运行安装程序。首次打开按提示准备应用专属依赖环境。
  4. 模型 CLI 需另外安装并认证。桌面桥接复用 Electron 内置 Node；WebUI 的桥接宿主另需 Node.js 20+。
  5. 更新前保存稿件，并在任务空闲时备份整个工作区。设置中检查更新；Mac 下载后在 Finder 替换 App，Windows 使用安装程序。

成功后应该看到什么

重新打开 App 后核对版本，再打开原工作区确认原稿与材料仍在。PyPI 包提供服务与 WebUI，不包含桌面 App。

失败与边界

首批 Mac 与 Windows 包均未签名，Mac 也未公证。核对官方来源与 SHA256 后使用系统的单应用许可入口，不要关闭整体安全防护。更新请求失败可从官方 Releases 获取安装包；不要删除工作区来修复下载错误。
