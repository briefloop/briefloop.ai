  • 英文报告贯穿需求、写作、修订和审阅，新增 10 套英文版式，导出标签跟随报告语言。

安装前准备

  • 使用本机已有的 Python 3.11 或更高版本，支持 Python 3.12。应用会创建专属环境并下载 BriefLoop 依赖，不会自动再安装一份 Python。
  • 桌面应用自带运行桥接。请安装并认证至少一个受支持的模型 CLI，或配置受支持的 API 提供方；模型用量由你的提供方账户承担。
  • 首次准备依赖需要联网；工作区与报告保存在本机。
  • Mac 安装包暂未签名和公证，macOS 可能提示无法验证开发者。

安装后，确认第一份稿件可用

  1. Mac 打开 DMG，将 BriefLoop 拷入 Applications；Windows 运行 EXE 安装程序。
  2. 首次启动准备依赖，再打开工作区，并认证模型宿主。
  3. 保存第一份稿件，生成 Word 并打开文件，确认完整流程。

首批两平台安装包均未签名，Mac 也未公证。核对官方来源与校验值后使用系统的单应用许可入口，不要关闭系统整体安全防护。

工作区保存在本地；使用云端模型、搜索或连接器时，相关内容会发送给所选服务。模型费与搜索费由对应提供方收取。
