What changes in 0.24.0

A shared entry point for BriefLoop Agent and Agent CLI, with recoverable drafts, attachments and report versions. Writing and revisions preserve citations; source search and research budgets work together, and Word exports retain linked sources and locations.

This release publishes Mac and Python / CLI 0.24.0. The Windows 0.24.0 release is deferred; its current installer remains 0.23.1.

Full release notes and validation scope · Installer versions are shown on the download cards.

Before you install

  • Use an existing Python 3.11 or newer; Python 3.12 is supported. The app creates its own environment and downloads BriefLoop dependencies. It does not automatically install another Python.
  • The desktop app includes the runtime bridge. At least one supported model CLI must be installed and authenticated, or configure a supported API provider. Model usage follows your provider account.
  • An internet connection is required for initial dependency setup. Workspaces and reports are stored locally.
  • The Mac package is not signed or notarized. macOS may show a developer verification prompt.

Install, then verify

  1. Mac: open the DMG and copy BriefLoop to Applications. Windows: run the EXE installer.
  2. Prepare dependencies at first launch, then open a workspace and authenticate a model runtime.
  3. Save a first draft and open its Word export to verify the complete path.

Both initial desktop packages are unsigned; the Mac package is also not notarized. Verify the official source and checksum, then use the OS permission for this app. Do not disable system-wide protection.

Workspaces are local. Cloud models, search and connectors receive relevant content when used. Model and search fees are charged by your chosen providers.
